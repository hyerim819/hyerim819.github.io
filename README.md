# p1ki.log

시스템 보안과 보안 기술 학습 과정을 기록하는 Jekyll 기반 개인 블로그이다.

## 구성

- 첫 화면: 유령 안내 화면
- 홈: 프로필, 포스트, 아카이브 폴더로 구성된 노트북 화면
- 콘텐츠: 카테고리·태그·아카이브와 개별 학습 포스트

## 티스토리 자동 동기화

`https://p1ki.tistory.com/rss`에 공개된 글을 GitHub Actions가 약 30분 간격으로 확인한다. 새 글은 `_posts`에 Jekyll 게시물로 추가되며, 티스토리에서 수정한 글도 다음 동기화 때 갱신된다.

동기화를 즉시 확인하려면 GitHub 저장소의 **Actions → Deploy Jekyll site to Pages → Run workflow**를 실행한다.

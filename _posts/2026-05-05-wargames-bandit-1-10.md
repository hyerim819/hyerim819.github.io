# Bandit 0 → 10 풀이 정리

이번 글에서는 OverTheWire Bandit 워게임의 **0단계부터 10단계까지** 풀이 과정을 정리해보려고 한다.
각 단계에서는 리눅스 기본 명령어를 활용해 다음 단계로 넘어가기 위한 비밀번호를 찾아야 한다.

---

## Bandit 0 → 1

처음 접속한 뒤, 현재 디렉터리에 어떤 파일이 있는지 확인하기 위해 `ls` 명령어를 사용했다.

```bash
ls
```

확인해보니 `readme` 파일이 있었고, 문제 설명에 따르면 이 파일 안에 다음 단계의 비밀번호가 들어있다고 했다.
따라서 `cat` 명령어를 사용해 파일 내용을 출력했다.

```bash
cat readme
```

`ls`는 현재 디렉터리의 파일 목록을 확인할 때 사용하고, `cat`은 파일 내용을 출력할 때 사용한다.

## Bandit 1 → 2

이번 단계도 기본적인 흐름은 이전 단계와 비슷했다.
현재 폴더 안의 파일을 확인한 뒤, 파일 내용을 읽으면 된다.

```bash
ls
```

하지만 이번에는 파일명이 `-`였다.
리눅스에서는 `-`가 옵션을 의미하는 경우가 많기 때문에 단순히 `cat -`를 입력하면 파일명으로 인식되지 않는다.

그래서 현재 디렉터리에 있는 `-` 파일이라는 의미로 `./-`를 사용했다.

```bash
cat ./-
```

파일명이 `-`처럼 특수한 의미를 가질 수 있는 경우에는 `./파일명` 형태로 현재 디렉터리의 파일임을 명확히 지정해야 한다.

## Bandit 2 → 3

이번 단계도 파일 내용을 읽는 문제였다.
하지만 파일명에 공백이 포함되어 있었다.

리눅스 명령어에서 공백은 인자를 구분하는 역할을 하기 때문에, 파일명을 그대로 입력하면 하나의 파일명으로 인식되지 않는다.
따라서 파일명을 따옴표로 감싸주었다.

```bash
cat "spaces in this filename"
```

파일명에 공백이 있을 때는 큰따옴표 `"` 또는 작은따옴표 `'`로 감싸서 하나의 문자열로 처리해야 한다.

## Bandit 3 → 4

이번 단계에서는 숨겨진 파일을 찾아야 했다.
일반적인 `ls` 명령어로는 숨김 파일이 보이지 않기 때문에 `-a` 옵션을 사용했다.

```bash
ls -a
```

숨김 파일 목록을 확인한 뒤, 해당 파일의 내용을 `cat`으로 출력해 비밀번호를 얻었다.

```bash
cat .hidden
```

처음에는 파일명에 `...`이 포함되어 있다는 점을 간과해서 조금 헤맸다.
숨김 파일은 이름이 `.`으로 시작하는 경우가 많기 때문에, `ls -a`로 꼼꼼히 확인하는 것이 중요했다.


`ls -a`는 숨겨진 파일까지 모두 보여주는 명령어다.

## Bandit 4 → 5

이번 단계에서는 여러 파일 중에서 사람이 읽을 수 있는 파일을 찾아야 했다.
문제에서 사람이 읽을 수 있는 파일은 ASCII 형식이라고 힌트를 주었다.

처음에는 아래처럼 파일을 하나씩 확인했다.

```bash
file ./-file00
```

하지만 파일이 여러 개라서 하나씩 확인하는 것은 비효율적이었다.
이후 `*` 와일드카드를 사용하면 한 번에 여러 파일의 형식을 확인할 수 있다는 것을 알게 되었다.

```bash
file ./*
```

출력 결과 중 ASCII text로 표시되는 파일을 찾은 뒤, 해당 파일을 `cat`으로 읽어 비밀번호를 얻었다.

`file` 명령어는 파일의 종류를 확인할 때 사용한다.
여러 파일을 한 번에 검사할 때는 `*` 와일드카드를 활용하면 편리하다.

## Bandit 5 → 6

이번 단계에서는 특정 조건을 만족하는 파일을 찾아야 했다.
파일 크기를 기준으로 원하는 파일을 찾기 위해 `find` 명령어를 사용했다.

```bash
find . -size 1033c
```

여기서 `.`은 현재 디렉터리부터 검색하겠다는 뜻이고, `-size 1033c`는 크기가 1033바이트인 파일을 찾겠다는 의미다.

조건에 맞는 파일을 찾은 뒤, `cat` 명령어로 파일 내용을 출력했다.

```bash
cat ./경로/파일명
```

`find`는 특정 조건에 맞는 파일을 검색할 때 매우 유용한 명령어다.
파일 크기를 기준으로 찾을 때는 `-size` 옵션을 사용한다.

## Bandit 6 → 7

이번 단계에서는 전체 시스템에서 특정 조건을 만족하는 파일을 찾아야 했다.
조건은 다음과 같았다.

* 파일 소유자: `bandit7`
* 파일 그룹: `bandit6`
* 파일 크기: `33 bytes`

처음에는 아래 명령어를 사용했다.

```bash
find / -type f -user bandit7 -group bandit6 -size 33c
```

하지만 `/`부터 검색하면 권한이 없는 디렉터리도 함께 탐색하게 되기 때문에, 에러 메시지가 많이 출력되었다.
이 때문에 원하는 결과를 찾기가 어려웠다.

그래서 에러 메시지를 숨기기 위해 `2>/dev/null`을 추가했다.

```bash
find / -type f -user bandit7 -group bandit6 -size 33c 2>/dev/null
```

조건에 맞는 파일 경로를 찾은 뒤, `cat`으로 내용을 확인했다.

```bash
cat /찾은/파일/경로
```


`2>/dev/null`은 에러 메시지를 화면에 출력하지 않도록 버리는 역할을 한다.
권한 문제로 에러가 많이 발생하는 상황에서 유용하게 사용할 수 있다.

## Bandit 7 → 8

이번 단계에서는 파일 안에서 특정 단어가 포함된 줄을 찾아야 했다.
이럴 때는 `grep` 명령어를 사용한다.

```bash
grep millionth data.txt
```

`grep`은 다음과 같은 구조로 사용한다.

```bash
grep 찾을단어 파일명
```

즉, `data.txt` 파일 안에서 `millionth`라는 단어가 포함된 줄을 찾아 출력하는 방식이다.


`grep`은 파일 내용 중 원하는 문자열이 포함된 줄을 찾을 때 사용한다.

## Bandit 8 → 9

이번 단계에서는 `data.txt` 파일 안에서 한 번만 등장하는 줄을 찾아야 했다.

먼저 `sort` 명령어를 사용해 파일 내용을 정렬했다.

```bash
sort data.txt
```

그 다음 `uniq -u` 명령어를 사용하면 중복되지 않고 한 번만 등장하는 줄을 찾을 수 있다.

```bash
sort data.txt | uniq -u
```

여기서 `|`는 파이프라고 하며, 앞 명령어의 결과를 뒤 명령어의 입력으로 넘겨준다.


`sort`는 내용을 정렬하고, `uniq -u`는 한 번만 등장하는 줄을 출력한다.
두 명령어를 함께 사용하면 중복되지 않는 값을 쉽게 찾을 수 있다.

## Bandit 9 → 10

이번 단계에서는 파일 안에 사람이 읽을 수 있는 문자열과 읽기 어려운 바이너리 데이터가 섞여 있었다.
그래서 `strings` 명령어를 사용해 사람이 읽을 수 있는 문자열만 추출했다.

```bash
strings data.txt
```

문제에서 비밀번호 주변에 `=` 문자가 있다고 했기 때문에, `grep`을 함께 사용해 `=`이 포함된 줄만 찾았다.

```bash
strings data.txt | grep =
```


`strings`는 바이너리 파일 안에서 사람이 읽을 수 있는 문자열만 추출할 때 사용한다.
여기에 `grep`을 함께 사용하면 원하는 패턴이 포함된 줄만 골라낼 수 있다.
